# Digger Game (работно име)

Малка 3D игра с багер: караш багер на строителна площадка, копаеш и местиш пясък, камъни и контейнери.

- Godot 4.7.2 (Mobile рендер), GDScript
- PC (Windows) и Android

## Пускане
Отвори папката в Godot 4.7.2 и натисни F5.

## Управление (PC)
| Клавиш | Какво прави |
|---|---|
| W / S | вериги напред / назад |
| A / D | завой наляво / надясно |
| ← / → | върти кабината |
| ↑ / ↓ | стрела нагоре / надолу |
| Q / E | рамо навън / навътре |
| Z | кофата гребе |
| X | кофата изсипва |
| V | смяна на камерата |
| R | отначало |

Как се гребе: спусни кофата в купчината, придърпай рамото (E) и свий кофата (Z). После вдигни стрелата, завърти кабината към камиона и изсипи (X).
