# Digger Game (работно име)

Малка 3D игра с багер: караш багер на строителна площадка, копаеш земята и пълниш самосвал.

- Godot 4.7.2 (Mobile рендер), GDScript
- PC (Windows) и Android

## Пускане
Отвори папката в Godot 4.7.2 и натисни F5.

## Управление (PC)
| Клавиш | Какво прави |
|---|---|
| W / S | вериги напред / назад |
| A / D | завой наляво / надясно |
| ← / → | върти кабината |
| ↑ / ↓ | стрела нагоре / надолу |
| Q / E | рамо навън / навътре |
| Z | кофата гребе |
| X | кофата изсипва |
| V | смяна на камерата |
| R | отначало |

Как се гребе: спусни кофата до купчината (↓), придърпай рамото (E) и свий кофата (Z) — зъбите режат земята и тя остава като дупка.
За по-дълбоко копане спускай стрелата, докато придърпваш. После вдигни стрелата, завърти кабината към камиона и изсипи (X).

## Текстури
`textures/` се генерират с `python3 tools/make_textures.py` (нужни: numpy, pillow).
